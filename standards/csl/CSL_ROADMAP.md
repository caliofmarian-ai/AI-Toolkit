# Canonical Specification Language (CSL)

# ROADMAP

Version: Draft 0.1

Status: Normative Planning

Classification: Canonical Roadmap

---

# 1. Purpose

The CSL Roadmap defines the planned evolution of the Canonical Specification Language.

Unlike ordinary project roadmaps, the CSL Roadmap governs the evolution of the standard itself.

Its objectives are to:

- establish implementation priorities;
- coordinate specification development;
- preserve long-term consistency;
- provide predictable evolution;
- prevent uncontrolled architectural changes.

---

# 2. Roadmap Principles

Every roadmap item shall:

- support the long-term vision of CSL;
- remain consistent with the Constitution;
- preserve backward compatibility whenever feasible;
- include measurable completion criteria;
- identify affected specifications;
- identify affected compiler components.

Roadmap items shall never contradict the Manifesto or Constitution.

# 10. Success Criteria

The CSL Roadmap shall be considered successful when:

- engineering knowledge is maintained only once;
- documentation is generated automatically;
- planning artifacts are generated automatically;
- code generation is compiler-driven;
- AI providers operate through the same canonical model;
- AI-Toolkit successfully demonstrates the complete workflow from Canonical Knowledge to Engineering Artifacts.
