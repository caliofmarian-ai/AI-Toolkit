# Canonical Specification Language (CSL)

# README

**Version:** Draft 0.1

## Purpose

The Canonical Specification Language (CSL) is an open engineering
standard for representing software engineering knowledge in a
deterministic, machine-readable and human-readable form.

## Vision

Software engineering should become knowledge-driven rather than
document-driven.

Humans maintain knowledge. Compilers generate engineering artifacts.

## Mission

Create an open engineering language capable of describing complete
software systems independently of programming language, framework, cloud
provider, AI provider or documentation format.

## Relationship with AI-Toolkit

CSL is an independent standard. AI-Toolkit is its reference
implementation.

## Motto

> Write Knowledge Once. Generate Everything.

## Fundamental Principle

> Knowledge is the Source. Everything Else is a Product.
