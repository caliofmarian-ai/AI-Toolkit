# Runtime Directory

Version: 1.0.0

Classification: Runtime Implementation Assets

CORE: CORE-023-010

RFC: RFC-0009

---

This directory contains implementation-specific runtime assets.

Contents shall include:

- Executables
- Configuration files
- Runtime state
- Compiled outputs
- Deployment assets

Implementation runtime assets are managed in `lib/python/runtime/`.

This directory provides RFC-0009 canonical separation between runtime
assets and Canonical Knowledge.
