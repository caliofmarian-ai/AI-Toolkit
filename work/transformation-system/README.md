# Transformation System

Purpose

The repository no longer stores only source code.

It stores the complete history of creation.

Every implementation begins with a Need.

Every Need becomes a Transformation.

Every Transformation must preserve:

- Need
- Research
- Hypothesis
- Implementation
- Execution
- Artifacts
- Verification
- Knowledge
- Evolution

No implementation is considered complete unless the complete creation
process can be reconstructed from a single transformation artifact.
