# AI-Toolkit Temporary Workspace

Purpose

This directory contains temporary engineering artifacts used during
canonical document reconstruction, migration and review.

Rules

- Never commit this directory.
- Files are temporary.
- Canonical documents remain the single source of truth.
- Every reconstruction must finish by merging the temporary document
  back into the canonical document.
- Temporary files should be removed after successful integration.
