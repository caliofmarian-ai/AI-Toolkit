# Canonical Relation Model v0.1

Status:
FROZEN

Definition:

A Canonical Relation is the minimum irreducible unit of Canonical Reality.

Every Canonical Relation SHALL define:

- Source
- Target
- Intent
- Justification
- Constraints
- Evidence
- State
- Continuity
- Recoverability

Everything inside Canonical Engineering is represented as
Canonical Relations.

Contracts are Canonical Relations.

Truth is a Canonical Relation.

Identity is a Canonical Relation.

Memory is a Canonical Relation.

Judgment is a Canonical Relation.
