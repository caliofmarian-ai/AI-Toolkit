# Canonical Admission — Need-Directed Memory Travel and Epistemic Sufficiency

**Organism:** AI-Toolkit
**Canonical function:** Need-directed travel through layered Memory
**Human Authority:** Owner

## Need

PCC-05 established Layered Memory anatomy, persistence, bidirectional travel,
and continuity toward deeper epistemic ancestry.

The remaining conceptual question was:

How does the organism know how deeply it should travel through Memory?

The existing Canon established that Memory must remain connected to deeper
Experience and Evidence and that the organism must preserve uncertainty,
conflict, provenance, and explicit unknown states.

However, the exact stopping principle for Memory research was not yet
materialized as one explicit canonical rule.

## Canonical ancestry examined

The admission was reconciled with existing canonical principles concerning:

- Memory and Experience distinction;
- Evidence-bounded conclusions;
- uncertainty;
- contradiction and conflict;
- provenance;
- minimum assumption;
- explicit unknown states;
- separation of epistemic organs;
- CSL derivation from Canon;
- Human Authority.

No existing canonical principle was identified that contradicted the admitted
rule.

The new Canon unifies those principles into an explicit physiology for
need-directed Memory research.

## Human decision

Human Authority explicitly accepted the rule that Memory research proceeds in
depth according to the need that initiated the research.

The search may stop when a sufficiently supported answer to that need has been
found.

Human Authority also accepted the strengthened boundary that the first
apparent answer is not automatically sufficient.

Relevant uncertainty, ambiguity, conflict, insufficient support, missing
provenance, or need for source verification may require deeper examination.

If available epistemic ancestry cannot support a sufficient answer, the
organism must preserve the unresolved state rather than fabricate an answer.

## Architectural consequence

Layered Memory remains the anatomy of stratified Memory and traversal.

The evaluation of need and sufficient recall depth is a cooperating
physiological function associated with Progressive Recall.

This distinction preserves the canonical separation of epistemic organs.
