**Semantic function:** Preserve and expose the exit from Memory toward deeper epistemic ancestry

must not become an epistemic dead end.

Layered Memory
→ Sedimentation
→ Transformation / Persistent Experience

PCC-05 must preserve this exit.

## Implementation

`MemoryEpistemicOrigin` represents the preserved exit from one
Sedimented Memory.

It carries only already-existing provenance:

- Memory identity;
- Sedimentation identifier;
- deeper provenance identifier;
- uncertainty when present.

`layered_memory_epistemic_origin(...)` exposes this route from any
Layered Memory node.

`traversal_epistemic_origin(...)` exposes it from the current position
of a living Layered Memory traversal.

## Epistemic boundary

This transformation does NOT claim that a provenance identifier is
itself Experience, Evidence, Transformation, or historical fact.

It does NOT resolve identifiers into historical bodies.

It does NOT manufacture missing Experience or Evidence.

It does NOT establish authority.

It does NOT establish truth.

It does NOT implement Progressive Recall.

It does NOT implement CSL.

It preserves the door and its address.

Later organs may use that address to reach the historical structures
they own.

## Uncertainty

boundary unchanged.

Absence of uncertainty remains absence.

No certainty is inferred from persistence.
