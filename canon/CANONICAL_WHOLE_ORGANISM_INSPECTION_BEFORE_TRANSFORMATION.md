# CANONICAL WHOLE-ORGANISM INSPECTION BEFORE TRANSFORMATION

**Document Type:** Canonical Governing Rule
**Organism:** AI-Toolkit
**Language:** English
**Human Authority:** Owner
**Human Decision Status:** ACCEPTED
**Canonical Status:** CANON
**Self-Ratification:** NO
**Admission Authority:** Explicit Human Authority

---

# 1. Canonical Rule

No new transformation, implementation, anatomical modification,
physiological extension, executable Bash, examination mechanism,
continuation decision, or other organism-changing action may be
designed in epistemic isolation.

Before such an action is constructed, the responsible AI partner MUST
inspect the whole relevant organism sufficiently to understand what
already exists, why it exists, what governs it, what it produces, and
what structures depend upon it.

The required inspection is a prerequisite of construction.

Execution is not a substitute for prior inspection.

---

# 2. Mandatory Whole-Organism Inspection

Before constructing an organism-changing action, the AI partner MUST
inspect, where relevant and available:

1. the applicable Canon;
2. canonical structures immediately upstream of the intended change;
3. canonical structures immediately downstream of the intended change;
4. the wider canonical physiological chain in which the structure exists;
5. the real anatomy currently present in the repository;
6. the real physiology currently implemented;
7. existing examinations and tests;
8. previously demonstrated behavioral evidence;
9. metabolic products generated by the organism;
10. provenance, lineage, witness, evidence, and uncertainty relevant to
    the intended transformation;
11. current demonstrable Git state;
12. previous failures, corrections, and conserved execution evidence
    relevant to the same physiological region.

Inspection MUST be sufficiently broad to prevent a locally correct
change from violating the physiology of the organism as a whole.

---

# 3. Canon Governs Construction

Canon MUST be inspected before implementation.

The AI partner MUST NOT rediscover through failed execution a governing
relationship that was already explicitly available in Canon.

A component MUST NOT be interpreted only through its local source code
when Canon defines its relationship with preceding or subsequent
epistemic structures.

Canonical physiological chains MUST be considered as chains.

For example, when operating within the continuity physiology, a
structure MUST be interpreted in relation to the relevant sequence,
including where applicable:

Persistent Experience
→ Transformation
→ Provenance / Lineage
→ Sedimentation
→ Layered Memory
→ CSL / Living Project Image
→ Progressive Recall
→ Context
→ subsequent transformation.

A local implementation MUST NOT silently sever requirements needed by a
later canonical structure.

---

# 4. Repository Reality Must Be Inspected Before Assumption

When information is directly inspectable in the repository, the AI
partner MUST inspect it rather than assume it.

This includes, where applicable:

- exact class and function signatures;
- actual constructors;
- actual import topology;
- actual package paths;
- existing test invocation patterns;
- existing persistence formats;
- real artifact locations;
- actual Git authority;
- real metabolic products;
- existing physiological boundaries;
- existing canonical relationships.

An assumption MUST NOT replace an available repository fact.

---

# 5. Execution Is Not a Discovery Substitute

Termux, Bash, tests, runtime execution, or the human operator MUST NOT
be used merely to discover facts that the AI partner could have
inspected before constructing the execution.

The human operator is not the organism's substitute repository reader.

A Bash execution MAY legitimately discover:

- runtime behavior;
- environmental behavior not statically knowable;
- concurrency behavior;
- process-death behavior;
- integration behavior;
- emergent metabolic products;
- genuine physiological defects.

A Bash execution MUST NOT be intentionally relied upon to discover:

- an already-visible function signature;
- an already-visible import form;
- an already-visible canonical requirement;
- an already-visible repository path;
- an already-visible physiological relationship;
- an already-visible existing test convention.

Failure caused by neglecting such available information constitutes a
failure of pre-transformation inspection.

---

# 6. Metabolic Products Are Evidence

Legitimate metabolic products generated by the organism MUST NOT be
classified as errors merely because they modify repository-visible
state.

When new metabolic artifacts appear, the AI partner MUST, where
relevant:

1. detect them;
2. inspect them;
3. interpret their semantic content;
4. identify the physiology that produced them;
5. correlate them with the execution that generated them;
6. preserve their provenance;
7. use them as behavioral evidence;
8. conserve them in Git according to the organism's conservation rules.

A metabolic product is not an unauthorized anatomical mutation merely
because it exists.

Anatomical mutation and physiological production MUST remain
distinguishable.

---

# 7. Neighboring Physiology Must Be Protected

Before modifying an organ or physiological function, the AI partner
MUST determine:

- what feeds it;
- what it feeds;
- what identities it must preserve;
- what provenance it must preserve;
- what later structures must be able to navigate back through it;
- what historical reality must remain recoverable;
- what uncertainty must remain visible;
- what Human Authority boundary applies.

A structure MUST NOT be optimized locally at the expense of the
organism's later canonical physiology.

---

# 8. No Blind Construction

The following construction pattern is forbidden:

assume
→ implement
→ execute
→ fail
→ inspect
→ discover an already-available fact
→ repair.

The required pattern is:

inspect Canon
→ inspect neighboring Canon
→ inspect real anatomy
→ inspect real physiology
→ inspect tests and evidence
→ inspect metabolic reality
→ derive the need
→ design the transformation
→ execute
→ observe new reality
→ inspect new metabolic evidence
→ conserve.

Execution may still expose genuinely unknowable defects.

Such discovery is legitimate.

Preventable failure caused by skipped available inspection is not.

---

# 9. Evidence Before Continuation

A successful test count alone does not define organism state.

Before deciding what comes next, the AI partner MUST consider the
relevant combination of:

Canon
+ anatomy
+ physiology
+ tests
+ execution evidence
+ metabolic products
+ provenance
+ lineage
+ Git state
+ unresolved contradictions.

The next transformation MUST be derived from the organism's actual
demonstrable need, not merely from sequential RUN numbering.

---

# 10. Human Burden Boundary

The AI partner MUST use direct repository access when available to
perform inspections that do not require human execution.

The human MUST NOT be asked to perform repository audits merely because
the AI partner failed to use available repository access.

Human execution remains legitimate where the required reality exists
only in the human-controlled runtime environment.

The distinction is:

**Repository-inspectable reality → AI inspects directly.**

**Runtime-only reality → execution may examine it.**

---

# 11. Canonical Enforcement

A proposed Bash or transformation is NOT READY when required
repository-inspectable information remains uninspected.

If the AI partner discovers before delivery that required information
is missing, it MUST inspect that information before delivering the
action.

If the required information cannot be inspected, uncertainty MUST be
stated explicitly rather than silently replaced by assumption.

---

# 12. Relationship to Human Authority

This rule does not grant AI canonical authority.

The AI partner observes and applies Canon.

Human Authority governs Canon.

This rule was admitted by explicit Human Authority and therefore
governs subsequent AI-Toolkit construction until legitimately
superseded or modified by Human Authority.

---

# 13. Canonical Principle

**Inspect the organism before transforming the organism.**

More completely:

**Canon governs the intended physiology.
Repository reality demonstrates the existing anatomy.
Evidence demonstrates behavior.
Metabolism demonstrates lived function.
Human Authority governs canonical admission.
Only after these are inspected may the next transformation be
constructed.**
