# Engineering Readiness Levels

Every engineering subsystem SHALL possess a measurable readiness level.

The canonical readiness levels are:

Level 0 — Concept

The capability exists only as an engineering idea.

---

Level 1 — Canonical Specification

Canonical specifications have been completed.

Architecture is stable.

Implementation has not started.

---

Level 2 — Prototype

Initial implementation exists.

Major functionality remains incomplete.

Architecture may still evolve.

---

Level 3 — Operational

Core functionality is operational.

Validation has been completed.

Engineering workflows are usable.

---

Level 4 — Production Ready

Subsystem satisfies all canonical requirements.

Engineering audits pass.

Security validation passes.

Documentation is complete.

Operational deployment is approved.

---

Level 5 — Self-Optimizing

Subsystem continuously improves itself using engineering evidence.

Learning, recommendations and optimization are active.

Engineering maturity SHALL be continuously measurable.
