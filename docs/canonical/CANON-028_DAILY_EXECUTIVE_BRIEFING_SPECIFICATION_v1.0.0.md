# CANON-028 — Daily Executive Briefing Specification

Version: 1.0.0

Status: Draft

Priority: Critical

---

# Purpose

Define the daily executive briefing generated by the AI CTO Platform.

The briefing provides the owner with a concise, evidence-based overview of the complete software ecosystem and recommends the highest-value actions for the current day.

---

# Mission

Enable the owner to understand the state of every project within minutes.

---

# Objectives

The Daily Executive Briefing shall:

- summarize all managed repositories
- identify the highest priority work
- estimate expected ROI
- identify risks
- recommend today's development plan
- explain every recommendation

---

# Invariants

Every briefing shall be generated from current repository state.

No recommendation shall be unsupported.

Recommendations shall remain fully explainable.

Owner approval remains authoritative.
