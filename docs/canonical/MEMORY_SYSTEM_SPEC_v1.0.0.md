# MEMORY SYSTEM SPECIFICATION

Version: 1.0.0

Status: Canonical

---

# PURPOSE

The Memory System is responsible for preserving all knowledge generated by AI Toolkit.

Every engine reads from memory.

Every engine writes to memory.

Memory is the foundation of autonomous behavior.

---

# MEMORY LAYERS

Layer 1

Session Memory

Stores temporary execution data.

Destroyed after session ends.

---

Layer 2

Workspace Memory

Stores current repository state.

Persists until work is finished.

---

Layer 3

Project Memory

Stores repository knowledge.

Includes:

Repository

Architecture

Issues

Plans

Reviews

Implementation history

---

Layer 4

Canonical Memory

Stores platform specifications.

Canonical documents are immutable sources of truth.

---

Layer 5

Global Memory

Stores reusable knowledge shared between repositories.

Examples:

Templates

Patterns

Best Practices

Prompt Library
