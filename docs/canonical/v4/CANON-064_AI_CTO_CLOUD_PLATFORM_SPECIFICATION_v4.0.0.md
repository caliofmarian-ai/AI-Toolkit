# Document Purpose

This specification defines the canonical architecture of AI CTO Cloud.

AI CTO Cloud is the official cloud platform that extends the local AI Toolkit Runtime into a globally connected engineering platform.

The Cloud Platform shall provide hosted Runtime services while preserving customer ownership, privacy, deterministic engineering behaviour and canonical governance.
