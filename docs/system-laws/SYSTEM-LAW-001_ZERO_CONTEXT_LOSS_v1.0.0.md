# SYSTEM-LAW-001 — ZERO CONTEXT LOSS

Version: 1.0.0

Status: ACTIVE

Priority: ABSOLUTE

Classification: SYSTEM LAW

---

# Law

The AI CTO Platform SHALL NEVER lose project context.

This law has precedence over every canonical specification.

Any implementation violating this law is considered non-compliant.

---

# Purpose

Guarantee uninterrupted software development regardless of:

- AI provider
- conversation
- session
- repository
- branch
- deployment
- restart
- infrastructure
- hardware
- operating system

Context continuity is mandatory.

---

# Definition of Context

Project context includes, at minimum:

- active project
- repository
- branch
- latest commit
- latest pull request
- roadmap
- current milestone
- current batch
- implementation status
- project memory
- owner decisions
- canonical state
- architecture state
- AI executor state
- pending reviews
- pending recommendations
- execution history

---

# Requirements

The platform shall always be capable of reconstructing:

- current development state
- next recommended action
- reasoning history
- repository health
- canonical coverage
- architecture compliance

without requiring manual explanation.

---

# Persistent State

Project state shall be stored independently from:

- conversations
- AI providers
- execution sessions

Persistent state becomes the authoritative source for project continuity.

---

# Continue Operation

The command:

Continue

shall always reconstruct the complete project state automatically.

The owner shall never be required to manually rebuild context.

---

# Validation

Every implementation shall prove that:

- no context is lost
- restart preserves state
- redeployment preserves state
- executor changes preserve state
- repository synchronization preserves state

---

# Violations

The following are considered critical violations:

- manual context reconstruction
- lost roadmap
- lost project memory
- lost implementation history
- inconsistent project state
- unrecoverable autonomous execution

---

# Compliance

Every future module shall explicitly demonstrate compliance with SYSTEM-LAW-001 before acceptance.

---

# Dependencies

None.

This document is a System Law.

All canonical specifications depend implicitly on this law.
